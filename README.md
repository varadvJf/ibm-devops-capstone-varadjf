# IBM DevOps Capstone Project – Accounts Microservice

This repository contains the IBM DevOps Capstone Project.

## Project Description

A RESTful Accounts Microservice demonstrating DevOps practices, including:

- REST API development
- Test-driven development
- Continuous Integration using GitHub Actions
- Security headers and CORS
- Docker containerization
- Kubernetes deployment
- Continuous Delivery using Tekton
